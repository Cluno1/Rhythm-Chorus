Sonorus Privacy Policy

Last updated: September 5, 2026

Overview

Sonorus is an open-source Android music player maintained independently by Cluno1. It does not include advertising, analytics, or third-party crash reporting.

Data on your device

Sonorus stores settings, playlists, listening history, local-library metadata, artwork, lyrics, scores, and downloaded Catalog media in app storage. Device audio is read for playback and library indexing; Sonorus does not upload device music.

Catalog connection

If you configure the private Catalog, Sonorus sends the server the user/device registration identifiers, a device public key, signed request metadata, and requests needed to list or download authorized Catalog content. The device private key remains non-exportable in Android Keystore. Catalog media may be downloaded from the configured object-storage provider.

Updates and external links

When update checks are enabled, Sonorus contacts the GitHub API and Release download hosts for Cluno1/Sonorus. GitHub receives ordinary network information such as your IP address and request headers. Links opened from About are handled by your browser.

Permissions

  • Audio/media read access: index and play music selected on the device.
  • Internet/network state: Catalog, object storage, and first-party updates.
  • Foreground service, notifications, wake lock, and audio settings: background playback and controls.
  • Install packages: hand a downloaded Sonorus APK to Android's system installer after explicit user action.

Sonorus does not request write-storage or all-files-access permission.

Control and deletion

You can clear caches and app data in Sonorus or Android settings. Removing a Catalog registration locally does not necessarily delete the server-side user/device record; contact the Catalog administrator for server-side deletion.

Open source and contact

Source is available under GNU GPL v3 or later at Cluno1/Sonorus. Report privacy questions through GitHub Issues.

Sonorus is an independent, unofficial derivative of Rhythm and is not affiliated with or endorsed by the upstream authors or Team ChromaHub.
