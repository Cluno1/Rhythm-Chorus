# Contributing to Sonorus

Contributions are welcome through [Cluno1/Sonorus](https://github.com/Cluno1/Sonorus).

1. Fork and branch from `main`.
2. Keep original SPDX/copyright headers and GPL attribution intact.
3. Add tests for behavior changes and run `./gradlew testGithubDebugUnitTest assembleGithubDebug`.
4. Use clear commits and open a pull request describing behavior, tests, and compatibility impact.

Translations live in `app/src/main/res/values*`. Sonorus does not currently claim a dedicated Weblate project; translation changes may be submitted by pull request while preserving resource names, placeholders, plurals, and XML escaping.

By contributing, you agree that your contribution is licensed under GPL-3.0-or-later. Do not submit music, scores, artwork, fonts, SoundFonts, secrets, or other content unless you have the right to redistribute it under its stated license.

Sonorus is derived from Rhythm. Changes must not remove or misrepresent upstream authorship, licenses, or Git history.
