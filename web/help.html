Help & How to Use

Getting Started Playing Music Library Customization Settings Troubleshooting Support

Getting Started

Installation & System Requirements

Rhythm requires Android 8.0+ (API 26) with 2GB RAM minimum and 50MB storage. Download from F-Droid, GitHub releases, IzzyOnDroid, or OpenAPK. For APK installation, enable "Install from unknown sources" in your device settings. The app is signed with an official keystore for security. You can also install via Obtainium for auto-updates from GitHub.

First-Run Setup

On first launch, Rhythm guides you through a quick setup: grant storage/media permissions, configure audio output preferences, choose your theme (light/dark/system), set up media scan mode (whitelist/blacklist), and optionally restore a previous backup. After setup, a media scan populates your library.

Essential Permissions Explained

  • Storage Access: Reads music files, album art, and manages playlists
  • Media Audio/Images: Access to music library and artwork (Android 13+)
  • Notifications: Playback controls, update alerts, and media session
  • Bluetooth: Wireless speaker/headphone support and device switching
  • Internet: LRCLib lyrics, Deezer/YouTube Music artwork, GitHub updates
  • Audio Settings: Volume control and audio focus management
  • Install Packages: In-app APK updates and installations
  • Media Playback Service: Background playback and lock screen controls

Material You Dynamic Theming

Android 12+ users get automatic color extraction from wallpaper. Choose from light/dark modes or system default. Custom color schemes available in Settings → Appearance → Theme Customization for personalized theming. The app uses Material 3 Expressive design with adaptive shapes and fluid animations.

Dual-Mode Architecture (Local + Streaming)

Rhythm 5 introduced a groundbreaking Dual-Mode Architecture. Switch between Local Mode for your personal high-res collection and Streaming Mode for server-based playback (Subsonic, Navidrome, Jellyfin). Each mode has its own dedicated library, home screen, and playback UI. Switch modes from the navigation drawer or settings.

Playing Music

Professional Media3 ExoPlayer Engine

Rhythm uses Google's Media3 ExoPlayer + FFmpeg decoder for studio-quality audio with gapless playback and perfect track transitions. Supports FLAC, ALAC, MP3, AAC, OGG, WAV, Opus, EAC3-JOC/Dolby Atmos (via FFmpeg), and more. Enable High-Resolution Audio mode in Settings → Audio to bypass Android system processing for the purest possible output to your DAC or headphone amp.

Replay Gain & Crossfade

Replay Gain normalizes perceived loudness across your library — choose between track gain (per-song) or album gain (maintains dynamic range within albums). Configure in Settings → Audio → Replay Gain. Crossfade smoothly blends the end of one track into the start of the next with adjustable duration (1–12 seconds).

Advanced Playback Features

  • Auto-Resume: Continues playback at exact position after app restart or device reboot
  • Smart Audio Focus: Handles phone calls, notifications, and other apps gracefully
  • Gapless Playback: Seamless transitions between tracks without silence
  • Multi-Select Batch Actions: Select multiple songs/albums/playlists to queue, share, or delete at once
  • Advanced Shuffle: True random, artist-aware, and weighted shuffle algorithms
  • Queue Management: Reorder, remove, and save playback queues with action dialogs
  • Active Song Highlighting: Visual indicators for currently playing tracks in lists
  • Rhythm Guard: Hearing safety — volume warning when listening at high levels for extended periods

Synchronized Lyrics with Advanced Features

Real-time lyrics with community-driven LRCLib integration. Word-by-word highlighting for karaoke-style experience, tap timestamps to seek, auto-scroll during playback, and manual reload option. Sync adjustment controls for lyrics that are off-beat. Supports multiple languages, OGG/Vorbis embedded lyrics, and synchronized highlighting. Use the built-in lyrics editor to adjust sync offsets and save per-track. Open lyrics in full-screen view for an immersive experience. Add the Lyrics widget to your home screen to see current track lyrics at a glance. Configure API endpoints in Settings → Advanced → API Management.

Professional 10-Band Equalizer with AutoEQ

Sophisticated 10-band equalizer with frequency-specific controls, preset profiles, and custom settings. Adjust bass, midrange, treble, and create personalized audio profiles. AutoEQ integration provides tuned presets for 6000+ devices with import/export functionality. Real-time audio processing with high-quality filtering algorithms.

Sleep Timer with Advanced Features

Customizable sleep timers with preset durations, fade-out options, and playlist continuation. Visual countdown indicator, automatic pause at specified time, and flexible duration selection from minutes to hours.

Device Output & Bluetooth Management

Advanced audio output selection with automatic Bluetooth device detection and switching. Manual device selection, audio focus management, and support for multiple simultaneous outputs. Enhanced Bluetooth handling for calls and notifications.

Library Management

Advanced Library Organization

Five main tabs: Songs, Albums, Artists, Playlists, and Explorer. Customize tab order and visibility in Settings → Library → Tab Order. Show/hide tabs based on your preferences. Each tab supports multiple sorting options and view preferences. The Explorer tab provides folder-based browsing with advanced storage access. In Streaming Mode, tabs reflect your server's media structure.

A–Z Scroll Bar

Navigate large libraries instantly with the alphabetical scroll bar. Drag your finger along the letter strip to jump to songs, albums, or artists starting with that letter. The scroll bar appears automatically when your library exceeds a threshold. Configure its behavior in Settings → Library.

Lightning-Fast Fuzzy Search

Intelligent search across song titles, artists, albums, genres, and lyrics. Real-time results update as you type. Search supports partial matches, typos, and multiple keywords. Access search from any library tab. In Streaming Mode, search queries your server's catalogue.

Genre-Based Smart Organization

Automatic genre detection with intelligent categorization. Browse music by genre with smart detection and organization. Filter library by genres, view genre-specific collections, and organize music by musical style.

Advanced Media Scanning

  • Full Scan Mode: Scans your entire library to ensure no songs are missed
  • Whitelist Mode: Include only specified folders for precise control
  • Blacklist Mode: Exclude unwanted directories and system folders
  • Explorer Integration: Manual folder browsing and selective adding
  • Real-time Updates: Trigger a rescan from Settings → Library → Rescan Media

Comprehensive Playlist Management

Create, edit, delete, and organize playlists with drag-and-drop reordering, sorting, and multi-select removal. Import/export in M3U, PLS, and other formats. Smart playlist suggestions based on listening habits. Backup and restore playlist collections. Choose between grid and list views for playlist browsing. Streaming playlists sync with your server.

Multi-Select Batch Operations

Long-press any song, album, or playlist item to enter multi-select mode. Select as many items as you want, then choose from batch actions: Add to Queue, Play Next, Add to Playlist, Share, or Delete.

Rich Metadata & Artwork Editing

View and edit comprehensive song metadata including title, artist, album, genre, year, and track number. Edit album artwork with permission handling. Metadata changes propagate across all screens. Artwork fetched automatically from Deezer and YouTube Music.

Customization

Advanced Theme Customization

Access Settings → Appearance → Theme Customization for complete control. Choose from predefined color schemes, create custom palettes, and preview themes before applying. Support for custom accent colors and theme variants.

Material Symbols & Expressive Design

Rhythm uses Material Symbols (variable-weight icon font) throughout the UI for crisp, scalable icons. The app follows Material 3 Expressive design language with adaptive shapes, fluid animations, and bold visual components.

Tablet-Optimized UI

On tablets, Rhythm automatically adapts with a multi-pane layout — library on the left, content on the right. The player screen, settings, and library views are all optimized for larger screens. Works in both portrait and landscape orientations.

Home Screen Widgets (Multiple Layouts)

Choose from multiple widget layouts (2x1 to 5x5) with real-time updates and Material 3 design. Customize playback controls, album art display, and information shown. Add the Lyrics widget to see current track lyrics on your home screen. Built with modern Glance framework for optimal performance and battery life.

Font Selection & Typography

Change the app's font from system fonts or import custom fonts. Access in Settings → Appearance → Font. Choose from various typography options to match your style preferences.

Library Tab Customization

Reorder navigation tabs (Songs, Albums, Artists, Playlists, Explorer) in Settings → Library → Tab Order. Arrange tabs to match your usage patterns and prioritize frequently used sections.

Grid vs List View Options

Choose between grid and list layouts for albums and artists. Grid view shows artwork prominently, list view provides more text information. Settings persist across app sessions.

Home Screen Customization

Reorder home screen sections with drag-and-drop in Settings → Home. Customize time and date formatting. Show/hide the Recents carousel for quick access to recently played tracks. Choose from different carousel styles. Set default screen to open on app launch.

Album Art Color Extraction

Dynamic theming based on album artwork colors. Extract vibrant colors from current track's artwork for immersive visual experience. Automatic color palette generation for consistent theming.

Settings & Advanced Features

Smart Settings Search

Powerful search functionality in Settings with real-time filtering. Type keywords to instantly find any setting across all categories. No need to navigate through menus — search finds everything.

Comprehensive Backup & Restore

Complete backup solution for playlists, settings, themes, equalizer profiles, and preferences. Restore everything when reinstalling or switching devices. Includes theme preferences, custom color schemes, and all user configurations.

Rhythm Stats 2.0

Comprehensive listening statistics broken into Overview (total play count, listening time, top genres), Songs (most played tracks), Albums (most played albums), Artists (favorite artists), and History (recent plays with timestamps). Stats reset at the start of each year with a summary notification. Access from the navigation drawer.

Offline Playback (Caching)

Streaming tracks are automatically cached locally for efficient replay. The cache reduces data usage and improves loading times for recently played tracks. Cache settings can be managed in Settings → Streaming.

Nearby Server Discovery

Rhythm can automatically discover Subsonic-compatible servers on your local network. When adding a server, tap "Discover" to scan for available servers without manually entering addresses. Works with Navidrome, Subsonic, and Jellyfin servers on the same subnet.

API Management & Configuration

Configure API endpoints for lyrics (LRCLib) and artwork (Deezer, YouTube Music). Set custom API keys, manage rate limits, and switch between community and personal API services. Enable or disable individual APIs in Settings → Advanced → API Management.

Intelligent Cache Management

Advanced cache system with manual controls and performance monitoring. Separate caches for artwork and lyrics. Automatic cleanup, size limits, and cache refresh options. Monitor storage usage and optimize performance.

Auto-Updates & Beta Program

Automatic update checking via GitHub releases with in-app download and installation. Beta program access for early feature testing. Choose between stable and beta update channels. Background update downloads.

Privacy & Data Management

Complete control over data usage and privacy. Manage what data is sent to APIs, control artwork fetching, and configure offline capabilities. No personal data collection — everything stays on your device.

Troubleshooting & Edge Cases

Installation & Updates

App Won't Install / "App Not Installed" Error

Signature mismatch is the most common cause — you cannot install a GitHub release APK over an F-Droid install (or vice versa) because they are signed with different keys. Uninstall the existing version first, then install from your preferred source. Stick to one source for updates.

Other causes: corrupted download (re-download the APK), insufficient storage (free up space), or Android blocking installation from unknown sources (enable in Settings → Security).

Update Stuck or Fails to Download

In-app updates download from GitHub Releases. If the download gets stuck: check your internet connection, ensure sufficient storage, or try downloading the APK manually from the Releases page.

Beta vs Stable Channel Confusion

Beta builds are published as GitHub Pre-releases. To switch back to stable, uninstall the beta and install the latest stable APK. Your settings and playlists can be restored from backup. Beta builds may have unfinished features and higher battery usage.

Cannot Downgrade to an Older Version

Android does not allow installing an APK with a lower versionCode over a newer install. You must uninstall the current version first, then install the older APK. Create a backup first (Settings → Advanced → Backup & Restore) as uninstalling erases all data.

Media Scanning & Library

Music Not Showing After Scan

Try these steps in order:

  1. Settings → Library → Rescan Media
  2. Check whitelist/blacklist — you may have excluded your music folder
  3. Use Explorer tab to manually verify files are accessible
  4. Ensure files are supported and not DRM-protected
  5. On Android 13+, verify Music and audio permission is granted
  6. Check if files are on external SD card — some Android versions restrict access
  7. In Streaming Mode, verify your server connection

Duplicate Songs in Library

Duplicates appear when the same file exists in multiple scanned locations. Use Blacklist mode to exclude one location. Rhythm does not deduplicate by audio fingerprint.

Wrong or Missing Metadata

Rhythm reads metadata from file tags, not filenames. Use a tag editor like Mp3tag or MusicBrainz Picard to fix tags, then rescan (Settings → Library → Rescan Media).

Files on SD Card / Network Shares Not Detected

Android's scoped storage limits external SD access. Use the Explorer tab to navigate manually. Rhythm does not support SMB/NFS — use Streaming Mode with a Subsonic/Navidrome/Jellyfin server for network playback.

Playback Issues

Audio Stuttering or Skipping

  • High-res audio on weak devices: Disable High-Resolution Audio in Settings → Audio
  • Bluetooth interference: Move closer to device, avoid crowded 2.4GHz areas
  • Battery optimization: Exclude Rhythm (Settings → Apps → Rhythm → Battery → Unrestricted)
  • Corrupted files: Verify the file plays in another player

No Sound / Wrong Audio Output

Check Device Output in the player screen (headphone icon). If Bluetooth is connected but no sound: disconnect and reconnect. After a phone call, audio may route to earpiece — toggle Bluetooth off/on.

Playback Stops When App Is Swiped Away

OEMs aggressively kill background services. Common fixes:

  • Samsung: Settings → Apps → Rhythm → Battery → Unrestricted
  • Xiaomi: Settings → Apps → Manage apps → Rhythm → Autostart → On. Lock app in recents
  • OnePlus/Oppo: Settings → Battery → Battery optimization → Don't optimize
  • Huawei: Settings → Apps → Rhythm → App launch → Manage manually → Allow all
  • Also disable "Pause app activity if unused" in Developer Options

Gapless / Crossfade Issues

FLAC, ALAC, MP3, AAC, and Opus support gapless playback. WAV files do not carry gap information. Crossfade takes priority over gapless — disable crossfade for true gapless. If crossfade causes popping, reduce duration or disable it.

Replay Gain Not Applying

Replay Gain requires REPLAYGAIN_TRACK_GAIN or REPLAYGAIN_ALBUM_GAIN tags. Use MusicBrainz Picard to add them. This is an experimental feature.

Equalizer & Audio Effects

Equalizer Not Affecting Sound

Ensure EQ is enabled in Settings → Audio → Equalizer. Some Bluetooth devices or USB DACs bypass Android's audio mixer — disable High-Resolution Audio mode. Restart app after toggling.

AutoEQ Preset Sounds Wrong

AutoEQ presets are community-measured. Try presets from similar headphone models. Manually adjust and save as a custom profile. Import/Export EQ settings to share.

Third-Party EQ Conflicts

Apps like Wavelet or device EQs conflict with Rhythm's built-in EQ. Only one EQ can process audio at a time. Disable one of them.

Lyrics & Artwork

Lyrics Not Loading or Wrong Timings

Lyrics come from LRCLib. Check internet and API settings. Use the sync adjustment in lyrics view to shift timings. Instrumental or obscure tracks may have no lyrics.

Artwork Not Fetching

Verify Deezer/YouTube Music API is enabled. Clear artwork cache (Settings → Advanced → Cache Management). Set artwork manually via the song info screen for missing albums.

Streaming Mode

Cannot Connect to Server

  • Verify URL includes protocol (https:// or http://)
  • Ensure server is running and network-accessible
  • Check credentials
  • For self-signed SSL, install the certificate on your device
  • Try Discover for local network servers

Streaming Quality Too Low

Your server may be transcoding. Check server transcoding settings (Navidrome: Settings → Transcoding, Jellyfin: Playback). For best quality, disable bitrate limits.

Server Online but Library Empty

Ensure your server has indexed music and your user account has library access. Try another Subsonic client to verify server health.

Widgets & Performance

Widget Not Updating

Remove and re-add the widget. Ensure music is playing. Exclude Rhythm from battery optimization. Some launchers have widget refresh delays.

Lyrics Widget Lagging

Widget refreshes via WorkManager periodically. Play a new track and wait 10–30 seconds. If still behind, remove and re-add.

High Battery Drain / Device Heating

Disable High-Resolution Audio and EQ if not needed. Standard-quality files consume less CPU. Exclude from battery optimization. If overheating persists, check for other running apps.

Backup & Device-Specific

Backup Fails or Partial Restore

Ensure sufficient storage and storage permission is granted. Backups are version-dependent — cross-version restore is best-effort. Transfer backup files manually to a new device.

Permission Denied (OEM Quirks)

Xiaomi: Permission → Show all permissions → enable all. Samsung: Allow background activity. Oppo/Realme: Allow background app management. After enabling, force-stop Rhythm and restart.

USB DAC Not Outputting Audio

Rhythm uses Android's native audio framework — no USB dialog appears. Verify DAC is detected by device. Ensure Developer Options → "Disable USB audio routing" is OFF. Try another player to confirm DAC works.

App Crashes on Launch

Clear app data (Settings → Apps → Rhythm → Storage → Clear Data). If persists, reinstall. Report crashes with logs from Settings → Advanced → Crash Log History.
